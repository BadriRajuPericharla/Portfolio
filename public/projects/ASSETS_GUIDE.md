# Game Project Assets Guide for Badri Raju

Drop your game screenshots or high-res gameplay previews directly into this directory (`/public/projects/`):

1. **BossFight2D**: `bossfight2d.png` (recommended 1280x720 or 1920x1080)
2. **ShadowSneak**: `shadowsneak.png`
3. **Arrow Escape**: `arrow-escape.png`
4. **Platformer2D / JungleJump**: `junglejump.png`
5. **Obstacle Game**: `obstacle-game.png`

### How the Automatic Detection Works:
- If a `.png` file with the matching name is present in this folder, the website automatically displays your real screenshot on the project card and inside the deep-dive modal.
- If no file is detected or while you are still capturing screenshots, the website gracefully falls back to the custom-designed, authentic vector game scene so the site never looks broken or empty!
